# Decision 0001: Name And Spine

## Decision

Use the repo name **MergeCode**.

The spine is:

> Given a repo, task, and patch, produce a maintainer-grade merge verdict with evidence.

## Why

The name is short, legible, and points directly at the outcome: code that should or should not be merged.

The spine avoids benchmark sprawl. It is demoable before any large corpus exists.

## Alternatives Considered

- MergeCourt: stronger metaphor, slightly less direct as a CLI/product name.
- PatchTriage: useful, but sounds narrower than maintainer-grade eval.
- ReviewBench: sounds too benchmark-first.
