# MergeCode brand assets

The mark is a **checkmark drawn as a commit graph**: the PR branch's commit (left node) runs down
into the merge point and up to main's commit (right node). It reads as both *merged* and *verified*.
It shares its ink/snow palette and wordmark font with its sibling project
[mcpsum](https://github.com/niravpatidar37/mcpsum).

| File | Use |
|---|---|
| `logo.svg` / `logo-dark.svg` | Lockup (mark + wordmark) for light / dark backgrounds. README header. |
| `icon.svg` / `icon-dark.svg` | Mark alone, transparent background. |
| `favicon.svg`, `favicon-32.png` | Browser tab / docs favicon (own tile, works on light and dark tabs). |
| `avatar-512.png` | GitHub / social avatar. |
| `social-preview.png` (from `social-preview.svg`) | Repository social preview (Settings → Social preview), 1280×640. |

## Colors

| Token | Hex | Contrast | Use |
|---|---|---|---|
| Ink | `#0B0F14` | 19.2:1 on `#FFFFFF` | Mark nodes and wordmark on light backgrounds; favicon tile |
| Snow | `#F2F0EA` | 16.6:1 on `#0D1117` | Mark nodes and wordmark on dark backgrounds |
| Green (light) | `#1A7F37` | 5.1:1 on `#FFFFFF` | Check stroke and "code" on light backgrounds |
| Green (dark) | `#3FB950` | 7.5:1 on `#0D1117` | Check stroke and "code" on dark backgrounds |

The build script checks contrast against GitHub's light (`#FFFFFF`) and dark (`#0D1117`)
backgrounds and fails below WCAG's 3:1 minimum for graphics. Every pairing above also clears 4.5:1.

## Usage

- Keep clear space around the lockup at least the diameter of a node.
- Below 120px wide, use the mark alone. Below 24px, use the favicon.
- Do not recolor, stretch, rotate, outline or add effects, and do not set the wordmark in another font.
- Use the dark variants on dark backgrounds.

## Rebuilding

Every asset is generated by `tools/build_brand.py`, so it is reproducible and reviewable as code.
The wordmark is JetBrains Mono ExtraBold (SIL OFL 1.1) converted to outlines. The font archive is
fetched from the pinned upstream release and verified by SHA-256. Output SVGs are checked for
scripts, event handlers and external references before they are written.

```sh
cargo install resvg --locked --version 0.48.1   # PNG export
uv run assets/brand/tools/build_brand.py
```
